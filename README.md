# 📚 Proyecto de Base de Datos - Restaurante 🍽️  
**Curso:** Inteligencia de Negocios  
**Carrera:** Ingeniería de Sistemas  
**Universidad Nacional de Cajamarca**  
**Ciclo:** 5.º

## 📌 Descripción  
Este repositorio contiene los documentos y recursos necesarios para el diseño e implementación de una base de datos orientada a la gestión operativa de un restaurante.  
El proyecto forma parte del curso de Inteligencia de Negocios, y busca fortalecer las competencias en modelado de datos, normalización, consultas SQL, manejo de sistemas de gestión de bases de datos (SGBD), Modelado de base de datos dimensionales e implementación del proceso ETl.

## 📚 Contenido  
- Recolección de Requisitos de negocio
- Diseño Entidad Relación
- Diseño Conceptual 
- Modelo relacional  
- Script de base de datos relacional de Restaurante
- Backup con datos base de la base de datos
- Backup con datos simulados de 5 meses
- Scripst de simulación de Data
- Base de datos Dimensional (Script y Modelo estrella)
- Informe de proyecto.
- Casos de uso y documentación técnica
